# Support

TradeOps Copilot is an educational portfolio project and does not provide operational support for trading, investment, settlement, compliance, or financial decisions.

## Ask for help

Use a GitHub discussion when enabled, or open a focused issue using the appropriate template. Include the commit or release, operating system, runtime versions, exact command, expected behavior, actual behavior, and a minimal reproducible example.

Remove tokens, credentials, private data, employer material, and real financial information before sharing logs or screenshots. For vulnerabilities or exposed secrets, follow `SECURITY.md` instead of opening a public issue.

## Scope

Maintainers may help with documented local setup, deterministic mock mode, tests, examples, and reproducible defects. They cannot provide access to third-party services, evaluate real transactions, review confidential systems, or offer financial/legal/compliance advice.
