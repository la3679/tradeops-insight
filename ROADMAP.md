# Roadmap

## Candidate future work

- wire the web-facing demo service to durable repositories and PostgreSQL checkpoints
- generate the frontend client directly from a published OpenAPI artifact
- add independently licensed market-calendar adapters and broader memo-NLP evaluation
- add object storage and a reviewed, opt-in public-source synchronization worker
- exercise provider adapters with user-supplied test accounts and cost budgets
- validate the Terraform reference in a non-production sandbox account
- conduct external accessibility, threat-model, and performance reviews

These are honest future items, not commitments or claims of present capability.
