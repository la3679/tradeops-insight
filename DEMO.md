# Demonstration script

Owner: project maintainer. Purpose: a safe, repeatable ten-minute product walkthrough.

1. Start `docker compose up --build -d` and open `http://127.0.0.1:3000`.
2. Point out the independent-project and synthetic-data labels.
3. Filter the exception queue and open a settlement-date mismatch.
4. Review immutable trade facts, deterministic explanation, evidence, and suggested actions.
5. Start the workflow as analyst and inspect its node trace and review interrupt.
6. Switch to reviewer and approve with the displayed version.
7. Confirm applied demo resolution and audit entry.
8. Switch to auditor and show that mutation controls are unavailable/denied.
9. Show the 50-case evaluation screen and provider/version metadata.
10. Open Grafana and API docs; close with the security boundaries and known limitations.

Restarting the API resets workflow mutations, making the walkthrough repeatable.
