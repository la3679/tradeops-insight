# Contributing

By participating, follow the [Code of Conduct](CODE_OF_CONDUCT.md) and the clean-room boundaries in [AGENTS.md](AGENTS.md).

1. Open an issue for material changes.
2. Branch from current `main`; use Conventional Commits.
3. Keep all trades synthetic and record provenance for public fixtures.
4. Run `npm run verify`, `npm run test:e2e`, and `docker compose config --quiet`.
5. Update behavior-facing documentation and include test/security evidence in the pull request.

Never commit secrets, employer materials, client data, copied internal policies, or generated performance claims. Security reports follow [SECURITY.md](SECURITY.md).
