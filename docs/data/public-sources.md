# Public source adapters

- **Owner:** Data and security maintainers
- **Purpose:** Document implemented and candidate enrichments without conflating public references with synthetic trades.

## Implemented: GLEIF LEI lookup

The GLEIF adapter performs one HTTPS lookup against the allowlisted `api.gleif.org` host. It accepts only check-digit-valid uppercase LEIs, requests JSON:API, enforces a five-second request timeout and one-megabyte response limit, validates the nested legal name/status shape, rejects mismatched LEIs and unknown statuses, and attaches a SHA-256 digest plus source locator.

The low-level adapter makes one attempt. Retry, backoff, cache, and circuit-breaker policy belong to the calling application/worker so a workflow can record every attempt consistently. Tests use in-memory recorded-shaped responses and never require the public network.

GLEIF reference data is used under its stated CC0 terms. The project does not use GLEIF branding or imply endorsement. Reserved demo LEIs generated by this repository must not be sent to GLEIF.

## Candidate adapters

- **U.S. Treasury Fiscal Data:** reference metadata only after the exact dataset, fields, and snapshot policy are added to the source registry.
- **SEC EDGAR:** issuer/filing metadata only, with the required identifying user agent, rate discipline, caching, and adapter-specific tests.

Fee-based FINRA feeds, CUSIP-licensed identifiers, subscriber data, and sources with unclear redistribution terms remain excluded.
