# Local performance baseline — 2026-08-24

Owner: performance maintainer. Purpose: record repeatable demo-scale measurements without production claims.

Environment: Windows host, Intel Core i9-13900H (20 logical processors), 47.6 GiB RAM, Docker Engine 29.5.3, Compose 5.1.4, local containers, no network model. Results include host/container scheduling noise and are not production capacity guidance.

| Path                                     | Configuration                                                   | Result                                                   |
| ---------------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------- |
| non-LLM API + exception/trade pagination | k6 2.2.0, 1 VU, 30 s, 56 requests bounded below demo rate limit | 0 failures; mean 13.74 ms; p95 31.36 ms                  |
| synthetic batch import acceptance        | k6, 1 VU, 10 unique idempotent requests                         | 10/10; 1.64 requests/s paced; p95 20.22 ms               |
| WebSocket small fan-out                  | k6, 5 simultaneous one-shot clients                             | 5/5 upgraded and received snapshot; p95 connect 10.60 ms |
| RAG retrieval                            | deterministic 30-document FAISS index, 1,000 searches           | mean 0.020 ms; median 0.019 ms; p95 0.023 ms             |
| worker delivery policy                   | 10,000 ordered in-process events                                | mean 0.002 ms; median 0.002 ms; p95 0.003 ms             |
| end-to-end mock graph                    | 100 invoke/interrupt/resume runs                                | mean 10.257 ms; median 9.871 ms; p95 12.345 ms           |

Raw k6 JSON summaries are in this repository's `performance/` directory. Reproduce API/import/WebSocket tests with:

```powershell
docker run --rm -v "${PWD}/performance:/scripts" grafana/k6:2.2.0 run /scripts/k6-smoke.js
docker run --rm -v "${PWD}/performance:/scripts" grafana/k6:2.2.0 run /scripts/k6-import.js
docker run --rm -v "${PWD}/performance:/scripts" grafana/k6:2.2.0 run /scripts/k6-websocket.js
uv run --directory backend --locked python ../scripts/benchmark_components.py
```

The initial unpaced stress attempt correctly triggered the API rate limiter and is excluded from the representative baseline. Pagination uses the first bounded 25-record page. Import measures acceptance/idempotency registration, not durable bulk I/O. Worker timing measures the delivery policy, not Redis/Celery transport. Repeat after substantive runtime or hardware changes and keep raw evidence.
