# Architecture documentation

- [System overview](overview.md) — context, deployable units, trust boundaries, and request/workflow flow.
- [Architecture decision records](decisions/README.md) — durable decisions and their consequences.

## Updating architecture

Update the overview when responsibilities, trust boundaries, or deployable units change. Add an ADR when a change selects a technology, creates a durable constraint, or reverses an earlier decision. Do not edit an accepted ADR to hide a change; supersede it with a new record.
